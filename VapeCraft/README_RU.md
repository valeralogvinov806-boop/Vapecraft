# VapeCraft — Minecraft 1.20.1 / Fabric

Исходный проект мода с предметами, 32×32 текстурами, рецептами и эффектом облака.

## Сборка
1. Установи JDK 17.
2. Установи Gradle 8.x (или открой проект в IntelliJ IDEA с поддержкой Gradle).
3. В корне проекта выполни `gradle build`.
4. Готовый JAR появится в `build/libs/`.

Нужен Fabric Loader 0.15+ и Fabric API для Minecraft 1.20.1.

## Игровая механика
- Используй устройство правой кнопкой мыши.
- Появляется облако частиц; ближайшие существа получают магический урон и отравление.
- Каждое использование расходует заряд (прочность предмета).
- Заряд восполняется крафтом нового устройства; картриджи и жидкость имеют отдельные рецепты.

## Важно
Это стартовая версия 1.0.0. Картриджи, жидкость, аккумулятор и испаритель уже имеют предметы и рецепты, но пока не имеют отдельного интерфейса обслуживания. Рецепт заправленного картриджа — способ подготовить расходник. В следующих итерациях можно добавить GUI обслуживания, перенос заряда между батареями, звук, отдельные частицы и настраиваемые конфиги.


## Автоматическая онлайн-сборка через GitHub Actions

1. Создай на GitHub новый репозиторий и загрузи в него содержимое этого проекта (включая скрытую папку `.github`).
2. Открой вкладку **Actions** в репозитории.
3. Выбери workflow **Build VapeCraft** и нажми **Run workflow**. При push в `main` или `master` сборка также запускается автоматически.
4. Открой завершившийся запуск и скачай архив **VapeCraft-Fabric-1.20.1** в разделе **Artifacts**.
5. Внутри будет собранный JAR из `build/libs`.

Если сборка завершится ошибкой, открой лог шага **Build mod** и пришли его сюда — помогу исправить.
